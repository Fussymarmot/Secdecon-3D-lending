# Secdecon-3D-lending

Рекламный сайт про портальные пушки из «Рика и Морти»: интро с порталом, раздел с 3D-моделью каждой пушки (крутится, разбирается) и ряд всех пушек внизу с формой покупки.

## Как запустить

Сайт использует ES-модули и загружает `.glb`, поэтому прямой двойной клик по `index.html` не сработает. Нужен любой локальный сервер:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000. Three.js подключается с CDN (jsDelivr, версия зафиксирована в `index.html` в блоке `importmap`), так что нужен интернет. Если понадобится работать офлайн, скачай `three@0.170.0` и поменяй адреса в `importmap`.

## Как добавить новую пушку

1. Экспортируй модель из Blender: File → Export → glTF 2.0 (.glb), включи **Apply Modifiers**, оси «+Y Up». Каждая отдельная деталь, которая должна разлетаться при разборке, — отдельный объект с понятным именем.
2. Положи файл в `models/`.
3. В `js/guns.js` у нужной пушки замени `model: null` на путь к файлу и заполни поля (`heading`, `short`, `sticker`, `price`, `lead`, `facts`, `parts`). Раздел на странице, карточка внизу и пункт в форме заказа появятся сами.
4. В `parts` у каждой детали перечисли имена объектов из `.glb` (поле `nodes`).

Дуло пушки должно смотреть в сторону -Z (после экспорта с «+Y Up»), модель вписана примерно в 4×4×4, а все детали — отдельные объекты без родителей (иначе деталь с родителем не будет разлетаться сама по себе).

Цвета у пушки свои: поле `accent: 'pink'` красит раздел, карточку и окно заказа в розовый (переменные в `css/root-style.css`, блок `[data-accent="pink"]`), а `light` задаёт подсветку в 3D (контровой свет, свечение изнутри и подсветку детали при наведении). Без этих полей пушка получается зелёной.

Куда деталь улетает при разборке, задаётся в `.glb` в поле объекта `extras` → `explode` (вектор `[x, y, z]`, модель вписана в куб примерно 4×4×4). Если поля нет, деталь просто уезжает от центра модели. Силу разлёта для всей пушки можно менять в `guns.js` (`explode`).

## Форма покупки

В `js/guns.js` в `SHOP.orderEndpoint` нужно указать адрес, куда отправлять заказы (POST, JSON с полями `gun`, `quantity`, `total`, `name`, `phone` в формате `+7XXXXXXXXXX`, `address`, `comment`). Пока адрес пустой, форма работает в демо-режиме: заказ никуда не уходит, а в консоли браузера печатается его содержимое. Цена `4990` у обеих пушек временная.

Номер телефона в форме проверяется в браузере: маска `+7 (XXX) XXX-XX-XX`, 10 цифр, код начинается с 3, 4, 8 или 9, одинаковые цифры не проходят. Подтверждение номера кодом из SMS требует сервера и провайдера SMS, в статичном сайте его нет.

## Cookie

При первом заходе внизу страницы показывается плашка о cookie (`js/cookies.js`, стили в `css/cookies-style.css`). Отказаться нельзя, кнопка только «Понятно»; выбор запоминается в cookie `secdecon_cookie_notice` на год. Текст политики лежит в `cookies.html`.

## Структура

- `index.html` — страница
- `js/guns.js` — список пушек и настройки магазина
- `js/viewer.js` — 3D-просмотрщик (вращение, разборка, подсветка деталей)
- `js/shop.js` — разделы коллекции, ряд карточек, форма заказа
- `js/portal.js`, `js/loader.js` — портал в интро и загрузочный экран
- `css/collection-style.css` — стили новых блоков
- `models/pushka1.glb` — Interdimensional Portal Gun (зелёная)
- `models/pushka2.glb` — See-through Portal Gun (розовая), собрана из `Pushka2.blend`: модификаторы применены, узлы `lid`, `trunk` (ствол), `frame`, `handle`, `button`
